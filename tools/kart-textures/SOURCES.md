# Race suit

The normal and roughness maps come from [Rough Linen · Poly Haven](https://polyhaven.com/a/rough_linen) under CC0. The 1K images were resized to 384 px, then packed into the GLB by the Blender script. The yellow dye, pattern, stitching and pilot geometry were made for this game.

The original rigged driver uses 1K base colour, OpenGL normal and roughness files from [Bi Stretch · Poly Haven](https://polyhaven.com/a/bi_stretch), CC0. Competition slick surfaces use the original generated `competition-slick-*.png` tiles.
